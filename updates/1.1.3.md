# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Fixed an issue on client where items were used on slots and not slots, there was a statement mistake that could cause bugs eventually.
2. Fixed on `addItemDurability` an issue where durability was actually never added.
3. Fixed on `getWeaponMetadata` a print `null` result that would be sent because of grammar mistake.
4. Fixed on `addItem` and `addContainerItem` for not stackable items (items with durability), when giving a non-stackable items (more than one) in once - like a command, their unique id waas actually only on the display but on their metadata, they all shared the same unique id.
5. Fixed on `removeItem` and `removeContainerItem` an issue that content.durability > 0 should be checked to prevent bugs and also fixed an infinite loop for `shouldLoopForRemoval` that would run forever if somehow a mistake occured on removal.
6. Fixed on `removeWeapon` a small grammar mistake that wouldnt cause any bug but its good to be fixed on second loop.
7. Fixed on `LoadPlayerInventoryContents` an infinite wait issue in LoadPlayerInventoryContents() when no character record is returned from the database. The function now validates the database result and safely exits if the character cannot be found.
8. Fixed on `upgradeContainerInventoryWeight` event an issue on database saving, it would add extra weight.
